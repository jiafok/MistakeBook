## 2. 必测业务不变式

以下为“任何一条失败即阻断发布”的核心不变式：

1. **不自动收录**：未调用提交接口前，`mistakes` 表不存在对应记录。
2. **预选可推翻**：`>=85` 的区域可被单击取消，取消后不进入待收录。
3. **可补选**：`<50` 的区域可被手动选中并成功收录。
4. **档位恢复**：取消选中后，区域回到其原本 band 的视觉状态，而非统一变灰。
5. **计数一致**：`已选择 = 预计新增 + 已存在`，且与实际提交结果一致。
6. **坐标不变**：缩放/平移后提交的坐标与原图坐标一致。
7. **归属隔离**：用户无法通过构造 `paper_id` / `question_region_id` 收录他人数据。
8. **幂等**：重复提交同一批不产生重复错题。

## 4. 接口测试

| 用例 | 检查点 |
| --- | --- |
| `GET /papers/{id}/regions` | 只返回本人试卷；包含 band 字段；分页正确 |
| `PATCH /papers/{id}/selections` | 只影响当前用户；非法区域 id 被拒绝 |
| `POST /papers/{id}/commit` | 校验归属、坐标、概率范围；返回逐题明细；幂等键生效 |
| 并发提交 | 同一用户双请求不产生重复记录 |
| 越权 | 他人 `paper_id` 返回 403/404，不泄露存在性 |

## 6. 回归范围

V1.1 变更后必须回归：

- 上传与文件校验（未被破坏）。
- OCR 结果页到工作台的跳转。
- 错题库筛选与详情。
- 已收录题目的复习计划与统计（确保 `selection_source` 与快照字段未破坏统计）。

## 7. 测试数据

需准备覆盖以下批改形式的样本页：

`√`、`✓`、`✔`、`×`、`✗`、`△`、`○`、`？`、红笔叉号、红笔圈、仅写分数、无标记。

至少包含：印刷体/手写体、清晰/模糊、正拍/斜拍、单栏/双栏、含公式。

## 8. 缺陷分级

| 级别 | 示例 |
| --- | --- |
| Blocker | 未提交即写入错题；越权可收录；坐标错位导致错题指向错误题目 |
| Critical | 计数与实际不一致；取消选中后无法恢复；批量操作影响隐藏区域 |
| Major | 草稿恢复失败；部分失败未提示；键盘不可用 |
| Minor | 文案、建议措辞、非关键样式 |
